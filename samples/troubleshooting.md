# Troubleshooting Common Project Issues

*An independently created sample for a fictional software product.*

## A task isn't visible

**Possible cause:** You're viewing a different project.

**Resolution:** Open the correct project and check its task list. Refresh the page if necessary.

## You can't create a project

**Possible cause:** Your account doesn't have project-creation permission.

**Resolution:** Contact your workspace administrator to check your access.
